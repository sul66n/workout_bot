# Workout Reminder Bot

Telegram-бот, который напоминает о тренировках и ведёт учёт: сделала или пропустила.

## Возможности

- `/add` — добавить тренировку: название, дни недели, время, список упражнений
- `/list`, `/delete` — просмотр и удаление
- напоминание приходит в нужные дни с кнопками «✅ Сделала / ⏭ Пропустила»
- `/stats` — сколько тренировок сделано за 30 дней
- `/timezone Europe/Riga` — свой часовой пояс
- расписание хранится в SQLite и восстанавливается после перезапуска

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Установи зависимости и настрой окружение:

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # впиши BOT_TOKEN
python bot.py
```

3. Открой бота в Telegram и отправь `/start`.

Тесты разбора ввода: `pip install pytest && pytest`.

## Структура

```
bot.py      # хэндлеры и планировщик напоминаний
db.py       # SQLite: пользователи, тренировки, отметки
parsing.py  # разбор «пн ср пт» и «18:30»
tests/      # тесты парсинга
```
